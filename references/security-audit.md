# 安全审计与验证范围

审计日期：2026-10-13（Asia/Hong_Kong）。对象：本仓库公开发布的 matlab-stk-com 文件夹；不是对整个 STK/MATLAB 产品作安全认证。

## 静态审计

- 从三个目录170个.m（22567行、896640字节）与2个.mlx（提取37行代码）提炼；source-inventory.csv 保存 SHA-256，并在打包时重新核对原代码未改变。
- SKILL.md 的 YAML/name/description/未完成占位符通过 skill-creator 官方 quick_validate.py；agents/openai.yaml 检查 UTF-8 编码和元数据。
- 校验相对文档链接、允许的文本类型、目录结构、文件路径及 SHA-256 manifest；创建者本地ZIP另做CRC、路径穿越和成员字节检查。
- 模板无 eval/evalin/str2num、shell 执行、下载、网络连接、注册表修改、递归删除或硬编码凭据。秘钥模式扫描为启发式检查，不保证检测所有敏感文本。
- 不运行原教程中的共享 Catalog 删除、WSC 注册、TCP 5001 开启或全局 Access 清空。
- 实例退出必须 quitOwned=true 且 OwnsApplication=true；普通释放与退出分离。退出自有实例会丢弃其未保存场景；需要保留时先显式保存。
- 单位用 onCleanup 异常恢复；不把源例中宽泛 catch 关闭场景作为恢复逻辑。
- 模板拒绝同名卫星覆盖、报告覆盖、引号/换行名称、输出路径中的 .. 和隐式网络路径；CSV 文本公式标记加单引号。
- 报告写入是调用者给定目录的显式副作用；源文件、用户现有场景及其他工具配置不修改。若磁盘写失败，可能留下部分新报告，需要核实结果后再清理。
- Skill 读取不自动执行脚本。日志、源码和报告中的文本不是工具指令；自有会话标记是工程约束，不是防恶意调用者伪造的权限边界。

## MATLAB 与 STK 验证

实际产品：STK 12.1.0（可执行文件版本 12.1.0.822）。目标 MATLAB：R2020b 9.9.0.1467703、R2023b 23.2.0.2365128。

历史运行日志保留在创建者本地，均以 VALIDATION PASSED 结束且无清理失败报警；自有实例已正常退出。仓库不公开本地日志、报告或进程信息，public-audit.json记录两份日志SHA-256以供创建者追溯。

验证内容：创建独立应用和场景；J2 传播与 J2000 六根数；一小时 LLA 61 个样本和物理量级；一天 Access 6 个窗口；全部区间型报告行数；成功/异常 DateFormat 恢复；场景/同名卫星保护；报告防覆盖；CSV 行数回读和公式文本保护；拒绝退出非拥有会话；自有场景关闭与应用退出。

两版 Code Analyzer 未发现语法错误；余下 4 条低影响提示为 char(10) 可读性、两个建议支持 string 的 cellstr 契约、一个冗余抑制注释提示。这些不代表全套 lint 零告警。

## 排查记录与限制

- 受限启动环境中 R2023b 曾在初始化 ddux_logging 崩溃，R2020b 曾无法创建 COM；使用正常本地执行权限后可运行。未修改 HOME、STK 注册或系统安装。
- 前期测试发现 onCleanup 嵌套共享变量失效和可见 STK 退出等待；已改用普通回调、显式自有场景关闭和退出选项，并重测。早期滞留实例仅按已记录 PID、启动时间、SkillSmoke 窗口身份清理；不会把进程终止写为模板正常断开流程。

- 模板主路径通过不代表所有 Provider、fixed 模式、空 Access、所有进阶许可/API 或全部原教程已运行；这些保持静态审阅和本地帮助核对范围。
